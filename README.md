# STT Performance Tester v0 — Latency Comparison

Цей застосунок є тестовим середовищем для вимірювання та порівняння затримки (latency) систем розпізнавання мовлення (STT) на платформі Android з використанням Vosk. Він дозволяє порівняти два режими роботи на одному пристрої з однаковим текстом:

- **Full Recognition** — повне розпізнавання всього словника.
- **Grammar-Constrained** — розпізнавання, обмежене граматикою поточного та наступного речень.

## Вимоги

- Java Development Kit (JDK) 17
- Android SDK
- Фізичний Android-пристрій з ОС Android 8.0+ (API 26+) для коректного тестування мікрофону та продуктивності (емулятори можуть давати некоректні затримки).
- Кабель USB для підключення телефону.

## 1. Підготовка проекту (ОБОВ'ЯЗКОВО)

⚠️ **Проект не працюватиме без української моделі Vosk, яку потрібно завантажити вручну.**

1. Завантажте українську модель **`vosk-model-small-uk`** з офіційного сайту:
   [https://alphacephei.com/vosk/models](https://alphacephei.com/vosk/models)
2. Розархівуйте завантажений ZIP-файл.
3. Перейменуйте розпаковану папку на `model-uk`.
4. Скопіюйте цю папку всередину проекту за наступним шляхом:
   `src/main/assets/model-uk/`

   _(Якщо папки `assets` не існує, створіть її)._

## 2. Збірка та запуск (через Термінал / Командний рядок)

Ви можете скомпілювати та встановити застосунок на телефон безпосередньо з терміналу (PowerShell, CMD, Bash), використовуючи Gradle Wrapper.

### Крок 2.1: Підготовка телефону

1. Увімкніть **"Режим розробника"** (Developer Options) на вашому Android пристрої.
2. Увімкніть **"Налагодження по USB"** (USB Debugging).
3. Підключіть телефон до комп'ютера за допомогою USB-кабелю.
4. На екрані телефону може з'явитися запит _"Дозволити налагодження з цього комп'ютера?"_ — натисніть **Дозволити** (Allow).
5. Перевірте, чи комп'ютер бачить ваш пристрій за допомогою `adb` (Android Debug Bridge):
   ```powershell
   adb devices
   ```
   _У списку має з'явитися ваш пристрій поруч зі словом `device`._

### Крок 2.2: Компіляція та встановлення

Відкрийте термінал у папці проекту:

```powershell
cd "D:\Project\RWK2"
```

Щоб **скомпілювати APK та одразу встановити його** на підключений телефон, виконайте:

**Для Windows (PowerShell/CMD):**

```powershell
.\gradlew installDebug
```

**Для Mac/Linux (або Bash на Windows):**

```bash
./gradlew installDebug
```

> **Примітка:** Якщо вам потрібно просто зібрати APK-файл без встановлення (наприклад, щоб передати його вручну), виконайте команду `.\gradlew assembleDebug`. Готовий файл з'явиться за шляхом `app/build/outputs/apk/debug/app-debug.apk`.

## 3. Збірка та запуск (через Android Studio)

Якщо ви віддаєте перевагу графічному інтерфейсу:

1. Відкрийте Android Studio.
2. Натисніть **File → Open** і виберіть папку `D:\Project\RWK2`.
3. Зачекайте, поки закінчиться синхронізація Gradle (процес внизу екрану).
4. Підключіть телефон по USB (як описано в Кроці 2.1).
5. Виберіть ваш пристрій у випадаючому списку пристроїв на панелі інструментів зверху.
6. Натисніть **Run** (зелений трикутник) або комбінацію клавіш `Shift + F10`.

## Як використовувати тестер

1. Запустіть додаток на телефоні.
2. Під час першого запуску додаток попросить **дозвіл на використання мікрофону** — надайте його. Також може знадобитися кілька секунд для завантаження моделі з `assets` в кеш пристрою.
3. Виберіть режим: **Full Recognition** або **Grammar-Constrained**.
4. Оберіть текст з випадаючого списку.
5. Натисніть **Start** і почніть читати текст вголос.
6. Спостерігайте за екраном:
   - 🟢 Зелений колір (та підкреслення) — слова, які рушій остаточно розпізнав (Confirmed).
   - 🟡 Жовтий колір — проміжні/попередні результати (Tentative).
7. Щоб призупинити, натисніть **Pause**. Щоб завершити, натисніть **Stop**.
8. Знизу екрану розгорніть панель, щоб побачити детальну статистику:
   - Partial result frequency (partials/sec)
   - Utterance-to-final-result time (ms)
   - Callback-to-highlight time (ns)
   - Inter-word highlight time (ms)
9. Натисніть **Copy Report**, щоб скопіювати результати у буфер обміну для подальшого аналізу.
