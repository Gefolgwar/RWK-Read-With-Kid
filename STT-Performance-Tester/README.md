# STT Performance Tester — Як запустити

## Найпростіший спосіб (Android Studio)

1. Відкрий **Android Studio**
2. Натисни **File → Open**
3. Вибери папку:
   `D:\Project\RWK2\STT-Performance-Tester`
4. Натисни **"Sync Project with Gradle Files"** (якщо з'явиться)
5. Потім натисни **Run** (зелена стрілка)

Якщо зелена стрілка не активна — напиши мені, і я дам тобі іншу команду.

## Альтернативний спосіб (термінал)

Відкрий PowerShell і виконай:

```powershell
cd "D:\Project\RWK2\STT-Performance-Tester"
./gradlew tasks
```

Напиши мені, що з'явилося після цієї команди.
